# AI-Assisted Cybersecurity Incident Intelligence Prototype

This is a simple feature prototype for the preliminary project report.

## What it does
- Accepts suspicious email text as input
- Detects phishing indicators
- Calculates a risk score and severity level
- Generates a structured incident intelligence report
- Allows the report to be downloaded as a text file

## How to run

1. Install requirements:

```bash
pip install -r requirements.txt
```

2. Start the app:

```bash
streamlit run app.py
```

3. Open the local Streamlit link in your browser.

## Prototype scope
This is not the full final system. It demonstrates the core orchestration workflow described in the report: evidence input, phishing analysis, evidence extraction, severity scoring, and report generation.
